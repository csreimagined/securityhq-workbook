Recommended cadence

Data integrity rules

  1. Separate realised value from projected value.
  2. Use customer data ahead of generic benchmarks.
  3. State confidence levels and evidence sources.
  4. Avoid counting one benefit twice.
  5. Agree calculation ownership in writing.
